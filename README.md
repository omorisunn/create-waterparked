## Build
##### By GitHub Actions
1. Fork this repository.
2. Go to Actions.
3. Select “Mod Workflow”
4. Start a new workflow.
The workflow will automatically download dependencies and build the mod.

##### By yourself
You need to create a libs folder and put Create: Coasters Simulated's mod jar into it.
```shell
cd create-waterparked
./gradlew build
```

<br><br>
**Warning:** Create: Waterparked is using mixins to work, it may have incompatibility with the latest version of Create: Coasters Simulated mod.
