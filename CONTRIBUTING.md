# Contributing
You can contribute by creating PRs.
There's some parts you can contribute:
- Fixing Bugs
- Adding Features
- Adding Shader Support

## Adding Shader Support
Core Interface: src/main/kotlin/net/omori_sunny/create_waterparked/client/compat/shaderpack/ShaderpackWaterAdapter.kt

Create a new adapter in src/main/kotlin/net/omori_sunny/create_waterparked/client/compat/shaderpack/

There're already built-in adapter for BSL and complementary shader.
